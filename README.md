## 📖 Descripción General

**JPMenu** es una suite completa de más de **70 módulos y mejoras** para Geometry Dash, actualizada y adaptada específicamente para **Geode v6 Beta** y **Geometry Dash 2.2091+**.

Diseñado tanto para jugadores casuales como para creadores y demon slayers que buscan optimizar su rendimiento, personalizar su experiencia y practicar de forma eficiente.

---

## 🕹️ Características Principales

| Categoría | Módulos destacados |
| :--- | :--- |
| **🎯 Nivel & Práctica** | StartPos Switcher, Hitboxes en tiempo real, Noclip Accuracy, Auto-Practice, Checkpoint Fix, Suicide Key, Desactivar Portales Espejo. |

## 🎮 Cómo Utilizar

* **En PC (Windows / macOS):**
  - Pulsa la tecla **`Tab`** en tu teclado para abrir o cerrar el menú.
  - Puedes asignar teclas rápidas a cada función haciendo clic en el icono del teclado dentro de la ventana de configuración del módulo.
* **En Móviles (Android / iOS):**
  - Toca el botón flotante táctil en pantalla para abrir el menú en cualquier pantalla del juego.

## 📥 Instalación

1. Asegúrate de tener instalado **Geode** para Geometry Dash 2.2091+.
2. Descarga el archivo `xonttfm.jpmodgeode.geode` desde la sección de **[Releases](https://github.com/XontTFM/JPModGeode/releases)**.
3. Copia el archivo descargado en tu carpeta de mods de Geode:
   * **Windows:** `Steam/steamapps/common/Geometry Dash/geode/mods/`
   * **Android:** `/sdcard/Android/media/com.robtopx.geometryjump/game/geode/mods/`
4. Inicia el juego y presiona **`Tab`**.

---

## 🛠️ Compilación desde el código fuente

Este proyecto utiliza **GitHub Actions** (`.github/workflows/build.yml`) para compilar binarios multiplataforma de forma automatizada con cada actualización.

Si deseas compilar localmente con **Geode CLI**:
```bash
geode build --install
```
