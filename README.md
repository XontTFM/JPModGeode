# JPMenu

Menú Mod de Calidad de Vida (QoL) para **Geometry Dash 2.2091** y **Geode v6.0.0-beta.2+**.

Basado en el proyecto original QOLMod de TheSillyDoggo, optimizado y actualizado para la versión más reciente de Geometry Dash.

## Características principales
- **Más de 70 funciones:** Speedhack, Show Hitboxes, StartPos Switcher, Solid Wave Trail, Noclip Accuracy, Auto-SafeMode, etc.
- **Interfaz intuitiva:** Navegación por categorías con iconos y personalización.
- **Multiplataforma:** Soporte para Windows, Android y macOS.

## Cómo usar
- **Windows / macOS:** Pulsa la tecla **Tab** en el teclado.
- **Android / iOS:** Toca el botón flotante en la pantalla.

## Créditos
- Basado en el código original de **TheSillyDoggo (QOLMod / GeodeMenu)**.
- Iconos de categorías por [Flaticon](https://www.flaticon.com/).
